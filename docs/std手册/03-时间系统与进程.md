# 时间、系统与进程

本章覆盖时间/日期、文件与目录、标准输入输出、日志、随机数、进程与 Worker。这里的 API 多数直接接触操作系统资源：文件、进程、管道和目录监听都必须显式关闭；GC 不会替代 `close()`。异步文件与定时器通过泵在主线程派发回调，回调执行期间不要阻塞事件循环。

## `DirWatcher.myl` — DirWatcher

**文件职责**：轮询式目录监听：基于名字、mtime 和大小快照做差异比较。 默认只看根目录；WatchRecursive 会递归到子目录（最多 32 层，跳过不可读子目录）。 不依赖 inotify/ReadDirectoryChangesW；适合低频配置/文件目录，不保证捕获同一毫秒内 同大小内容的修改。需要事件循环集成时用 DirWatchPump。

### DirWatcher

**类型**：`pub class DirWatcher`（class）

轮询式目录监听：基于名字、mtime 和大小快照做差异比较。
