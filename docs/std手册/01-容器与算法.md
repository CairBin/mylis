# 容器与算法

本章覆盖 `Vec`、`Map`、`Set`、`HashMap`、`BTreeMap`、`BTreeSet`、`Deque`、`Queue`、`Stack`、`PriorityQueue` 及其迭代器和通用算法。选型时先看是否需要有序遍历、是否需要哈希键、是否需要双端操作；所有容器都是单线程、非并发安全的值语义对象。

## `BTreeMap.myl` — BTreeMap

**文件职责**：BTreeMap<K, V>：有序 B 树映射（最小度数 2，单节点 1..3 个 key）。 节点存放在扁平数组中，children 只存节点下标，不生成递归 GC 对象。 查找/插入/删除 O(log n)，采用标准 B 树借位与合并。 键必须满足 Ord；keys()/values() 按 key 升序返回。容器本身不保证并发安全。

### BTreeMap

**类型**：`pub class BTreeMap<K: Ord, V>`（class）

BTreeMap<K, V>：有序 B 树映射（最小度数 2，单节点 1..3 个 key）。

**公开方法**：

| 签名 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `init() -> void` | 无 | `void` | 构造并初始化对象；参数写入实例状态。除类说明特别指出外，不在此处分配 OS 资源。 |
| `set(K key, V value) -> void` | K key, V value | `void` | 按键写入：存在则覆盖，不存在则插入；保持 key 有序。 |
| `insert(K key, V value) -> bool` | K key, V value | `bool` | 不存在时插入并返回 true，存在时覆盖并返回 false。 |
| `get(K key) -> Option<V>` | K key | `Option<V>` | 按 Ord 查找；存在返回 Some(value)，否则 None。 |
| `containsKey(K key) -> bool` | K key | `bool` | key 存在时返回 true。 |
| `getOr(K key, V fallback) -> V` | K key, V fallback | `V` | key 存在时返回对应 value，否则返回 fallback。 |
| `remove(K key) -> Option<V>` | K key | `Option<V>` | 删除 key 并返回旧 value；不存在返回 None。 |
| `firstKey() -> Option<K>` | 无 | `Option<K>` | 返回最小 key；空映射返回 None。 |
