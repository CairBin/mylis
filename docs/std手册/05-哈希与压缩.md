# 哈希与压缩

本章覆盖 CRC-32、MD5、SHA-1、SHA-256 和 gzip。哈希类 API 都是纯 Mylis 实现，输入按 UTF-8 字节处理，输出为小写十六进制；MD5/SHA-1 仅为兼容既有校验值，新安全场景使用 SHA-256。gzip 压缩端会选择 stored、fixed Huffman、dynamic Huffman 中更小的结果，解压端校验 CRC32 与长度。

## `Gzip.myl` — Gzip

**文件职责**：Gzip（RFC 1952）压缩/解压。压缩端同时尝试 stored、fixed Huffman + LZ77 与 dynamic Huffman + LZ77，选择更小的结果；dynamic 码长超过 15 位时回退。 解压端支持 stored、fixed 和 dynamic Huffman 三种 DEFLATE block，支持多成员拼接流，并校验每个成员的 CRC32 与长度。

### Gzip

**类型**：`pub class Gzip`（class）

Gzip（RFC 1952）压缩/解压。

**公开方法**：

| 签名 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `static Compress(string text) -> u8[]` | string text | `u8[]` | 把文本按 UTF-8 编码后压缩为 gzip 字节流。 |
| `static CompressBytes(u8[] data) -> u8[]` | u8[] data | `u8[]` | 把任意字节压缩为 gzip 字节流。 |
| `static DecompressBytes(u8[] data) -> Result<u8[], IoError>` | u8[] data | `Result<u8[], IoError>` | 解压 gzip 字节流；校验失败/格式错误返回 IoError。 |
| `static DecompressText(u8[] data) -> Result<string, IoError>` | u8[] data | `Result<string, IoError>` | 解压并把结果按 UTF-8 解码为字符串。 |
