# 文本与数据

本章覆盖字符串拆分/拼接、`StringBuilder`、字节缓冲、Base64、CSV、JSON、路径工具、正则和 Unicode 范围表。除 `Path`/`Text` 这类纯字符串工具外，解析器都返回 `Result` 或 `Option`，调用方必须处理失败分支；正则匹配偏移是 UTF-8 字节偏移，不是字符下标。

## `Base64.myl` — Base64

**文件职责**：Base64：RFC 4648 标准字母表，编码固定补 `=`，解码接受标准字母表与 ASCII 空白。 Decode/Encode 面向 UTF-8 文本；DecodeBytes/EncodeBytes 面向任意二进制字节。 解码严格检查长度、非法字符、填充位置、填充数量和未使用的尾部位。

### Base64

**类型**：`pub class Base64`（class）

Base64：RFC 4648 标准字母表，编码固定补 `=`，解码接受标准字母表与 ASCII 空白。

**公开方法**：

| 签名 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `static Encode(string text) -> string` | string text | `string` | 把文本按 UTF-8 字节编码为 Base64 字符串。 |
| `static EncodeBytes(u8[] b) -> string` | u8[] b | `string` | 把任意字节编码为 Base64 字符串。 |
| `static Decode(string text) -> Result<string, string>` | string text | `Result<string, string>` | 解码为 UTF-8 字符串；非法 Base64 或非法 UTF-8 返回 Err。 |
| `static DecodeBytes(string text) -> Result<u8[], string>` | string text | `Result<u8[], string>` | 解码为字节数组；非法字符/填充返回 Err。 |
